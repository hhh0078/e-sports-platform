## 实施步骤

1. 默认游戏轮播返回两段文案，修正当前空文字的来源；未知游戏使用不带未经审核名称的通用文案。
2. 增加显式、一次性的游戏轮播补齐命令，只有现有平台根管理员可执行。事务内备份配置、校验、后置审核、审计与主动缓存失效；保留已有自定义内容及审核拒绝占位。
3. 只补缺少文案的游戏图层。保留原图片、跳转、排序、平台轮播、公告、文章、提示和私密配置；重复执行不重复添加，不覆盖管理员后续修改。
4. 检查13款游戏在320/390微信模拟器中的完整文字、字号、透明背景、安全区、指示点与目录位置；通过后端事务测试、前端现有检查及H5/正式微信构建。
5. 中文提交并推送本次分支。宝塔MCP重新预检并完整备份后，仅构建和切换API镜像，显式补齐线上文案，核对13游戏、保留项和24小时缓存失效。

## 验收边界

本次不更换图片、不修改交易和资金规则，不创建生产登录会话或测试订单。模拟器、自动化与线上接口检查分别记录；不把构建通过视为小程序上传发布或真机验收。
