# 公共背景与个人中心验收

文件作用：记录本轮公共背景、个人中心头部和钱包文案调整的范围、实际验证及复测方法；不把模拟器结果当作真机或真实资金验收。

## 本轮调整

- 主内容视口、原生滚动层及二级页面正文显式绘制当前游戏的 `--bg`。原有卡片、封面、按钮、滚动和点击层级不变，减少透明合成层露出其它底色的机会。
- 个人中心原渐变在108%还有中间色标，后面的100%终点会被CSS规则推到108%，图片末端未能变成页面底色。现在按0%／55%／100%递增，末端完全使用当前游戏背景色。
- 头像、昵称整体上移12px，保留原生状态栏和胶囊避让。头部390px宽为168px高，320px宽为140px高；订单区顶部8px。
- 钱包仍分别显示可提现收入、进行中、结算中、提现中及充值款；充值一行改为“充值余额（仅消费）”。充值与可提现不是同一资金：充值用于消费，通过结算和资金审核的服务收入才可提现。本轮不改任何金额、账本或提现规则。

原图中正文中部的横向黑块在冷启动检查时未稳定复现。实测主根容器完整铺满844px窗口，不能将早期的高度猜测当作根因。本次通过公共层显式同色，并检查主题、切换、滚动前后及截图像素连续性来验收防露底修复。

## 已执行结果

前端451项测试、严格类型检查、41页规范检查、H5及正式微信构建通过。320／390微信模拟器各18项检查、各32张官方原图、各24个像素采样点通过，最大背景色差1，未捕获运行异常和颜色告警，原游戏偏好已恢复。见[汇总](../output/background-continuity/summary.json)。

实际界面验证使用现有dev工程。旧build窗口缺少运行时映射，相关尝试没有计入通过；正式包单独确认生产API、合法域名校验开启且无私有开发配置。当前工作区中用户原登录按钮文案及格式保持原样，提交只纳入本轮调整。

## 用户复测

1. 进入个人中心，检查封面底部自然过渡到正文背景，头像昵称与订单之间没有原来的大段留白。
2. 主导航来回切换，再在三角洲、王者等主题之间切换，个人中心滚到底再回顶部，确认没有横向黑块。
3. 打开登录、协议、个人资料和钱包等二级页，滚到底，检查背景一致且内容能正常滚动。
4. 登录后核对原钱包金额不变；充值款与可提现收入分别正确显示。此步骤及真机渲染需要本人实测，本轮访客截图不代替真实账户资金验收。

本轮只调整前端。正式小程序包重新构建不等于已重新上传、审核或公开发布。
