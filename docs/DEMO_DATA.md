# 演示数据

本项目提供独立的 `jijie-demo` 命令，适用于本地验收和源码展示。API 启动时不会自动导入这批数据；正式环境也必须由运维显式执行。

演示人物、组织、订单、聊天和评价均为虚构。它们的编号统一以 `demo_` 开头，数据库记录同时带有 `is_demo: true` 和 `demo_version: 1`。公开名称、服务说明、聊天和评价明确标注“演示”，不能把这些数量、认证、收入或评价宣传成真实经营成果。

| 内容 | 数量 | 展示内容 |
| --- | ---: | --- |
| 普通用户 | 60 | 42 个可展示接单身份、18 个玩家身份；全部没有真实手机号和微信身份 |
| 俱乐部 | 6 | 图文介绍、游戏范围、押金规则说明、考核说明 |
| 成员关系 | 42 | 36 条通过记录、6 条申请中记录 |
| 服务 | 130 | 13 款游戏各 10 条，使用现有游戏封面和分类 |
| 订单 | 52 | 未支付、待接单、服务中、待验收、完成、取消、退款及平台介入等状态 |
| 聊天 | 260 | 每单 1 条系统说明和买方、打手、俱乐部管理、平台管理各 1 条示例 |
| 评价 | 8 | 只关联完成的演示订单；评分和成交数由对应示例记录计算 |
| 几何头像 | 60 | 本地生成 PNG，存储在数据库，不增加小程序代码包素材 |

## 导入和查看

先启动一次 API，完成数据库结构和游戏配置初始化。命令只连接 `DATABASE_URL` 指定的 PostgreSQL，不连接 Redis，不创建会话，不调用 `App.New`，不会新增生产管理员。

在项目 `backend` 目录中执行：

```bash
# 使用当前 shell 已配置的 DATABASE_URL；默认是本机 jijie_dev。
go run ./cmd/demo seed

# 查看双重标记的演示记录总数。
go run ./cmd/demo status
```

也可以编译为独立程序：

```bash
go build -o bin/jijie-demo ./cmd/demo
./bin/jijie-demo seed
./bin/jijie-demo status
```

容器镜像包含该程序时，运行：

```bash
docker compose exec api /app/jijie-demo seed
docker compose exec api /app/jijie-demo status
```

`seed` 的输出数字表示本次新增数量。重复执行不会覆盖既有记录，正常情况下第二次所有新增数量都是 `0`。如果同名编号已被无演示标记的记录占用，整个导入事务会拒绝并回滚。

这些账号没有登录入口，不能通过开发登录接口指定 `demo_user_*` 来冒用身份。演示服务不能下单，演示订单不包含微信 OpenID、商户支付流水或退款流水。押金字段仅展示俱乐部规则，成员状态不会被描述为押金已支付或资金已托管。

管理员可以通过管理列表查看演示订单和四方聊天；游客可以浏览演示用户、俱乐部、服务和已完成订单对应的公开评价。原有五个本地验收身份继续用于真实操作流程测试，演示账号与这些身份互不替代。

后台经营概览排除演示用户、俱乐部、服务和订单，演示收入与演示售后不计入金额或待办。演示记录保持只读；即使订单编号本身不是演示编号，只要关联了演示服务、用户或俱乐部，也不能支付、退款、发消息、上传证据或评价。

## 清理

```bash
go run ./cmd/demo clear
# 或：docker compose exec api /app/jijie-demo clear
```

清理仅针对本版本的双重标记记录，不会按前缀删除所有数据，也不会删除原有用户、游戏配置、订单或证据。

删除前会锁定有关表并检查业务引用。如果真实订单、真实成员关系、真实聊天或证据引用了演示对象，或者演示订单混入真实参与者、支付标识、身份资料，整笔清理会拒绝并回滚。演示聊天、评价或图片证据关联真实订单、发送者、所有者或俱乐部时同样拒绝。真实用户或游戏配置使用了演示头像时也会拒绝，避免留下失效图片。此时请先核对错误信息指出的业务关系，不要绕过保护直接按 `demo_%` 批量删除。

整个操作完成后释放锁。重复清理是安全的；没有演示数据时各项删除数量为 `0`。

## 验证

专项测试运行在独立临时 schema 中，不重置本地演示或真实业务数据：

```bash
TEST_INTEGRATION=true go test -race -count=1 ./internal/app -run 'TestIntegrationShowcase|TestIntegrationOverviewExcludesShowcase|TestIntegrationDemoResourceReferenceBlocked'
```

测试覆盖生成数量、13 款游戏、订单状态、四方消息、禁止演示登录和下单、二次导入幂等、原有资料不变、双向真实引用保护、命名碰撞、事务回滚、统计隔离和演示标记保留。
