# 玩家页与封面系统改版

文件作用：记录本轮参考图审查、设计目标与实际实施顺序。2026-10-18。

## 先设计再实现

用户参考图：`design-reference.png`。本轮修改前实屏：`../output/redesign/before.png`。设计目标图：`player-design-v2.png`（内置 ImageGen，参考原图生成，2026-10-18）。目标图只用于界面比例和版式，不会拆出其中的人物冒充官方游戏素材。

旧版主要问题：额外品牌栏和介绍段落将服务列表推到首屏底部；泛游戏原创图无法辨识具体游戏；游戏入口过暗且字号小；卡片图文割裂。此前视觉“通过”不代表符合本次参考图要求。

本轮布局采用390px宽移动端：230px通栏主视觉，紧接可横滑游戏图标、分类和紧凑工具栏，两列图片卡片，底部四项导航。原图状态栏由设备负责，不复制到页面；用户要求的玩家/打手/订单/我的保留为四项。原图虚构承诺及销量改为真实服务内容、价格和成交数。

## 素材与数据

真实封面/图标按游戏单独归档到`backend/internal/assets/covers/official/`，来源见`ASSETS.md`。原始官方图保留人物识别，不使用AI仿造角色。游戏增补依据与数据口径见`GAME_POPULARITY.md`。

底图存`cover_url`，文案存`labels`数组（文字、前景、背景、位置、字号），前端使用`image`和独立`view`渲染。不会调用canvas导出合成封面。新建和换游戏随机底图，编辑保持已有底图，换底图保留文字。不同尺寸共用同一360×225坐标布局，自动避让。

## 交付门槛

- 真实页面对照参考图/设计图逐项检查字体、区域比例、颜色、素材、内容。
- 13游戏图标、封面均加载，切换更新主题/分类/服务。
- 六文案保存重开、换图不丢文字、发布审核和陌生账号权限检查。
- H5 320/390px与微信开发者工具实屏；后端真实PG/Redis race测试和交易回归。
- 实际剩余限制写入验收文档，不将编译通过等同上线可用。

## 最终实现与验收

本轮完成13款游戏、30张官方底图、13个独立图标；主视觉/游戏入口/双列卡片按先行设计稿落地，服务卡片与交易继续读真实接口。排序和文字位置采用明确的菜单/九宫格按钮。

已修复默认三角洲隐藏前两个热门入口、主视觉硬黑边、H5按钮默认边距、宽文字裁切和分页使用未提交关键词的问题。最终同尺寸实屏比较、双端操作和可追溯截图见项目根目录 [design-qa.md](../design-qa.md)，业务验收见 [ACCEPTANCE.md](ACCEPTANCE.md)。
