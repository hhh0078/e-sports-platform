# 游戏范围与推荐顺序依据

文件作用：记录游戏分类扩展、推荐顺序的依据，以及公开热度指标的日期和口径。核查日期：2026-10-18。

## 结论

本地版覆盖 13 款游戏，首页默认首排为王者荣耀、和平精英、三角洲行动、金铲铲之战、无畏契约。完整顺序为：

`honor → peace → delta → tft → valorant → lol → valorantm → cfm → arena → codm → identityv → narakam → eggy`

这是结合用户指定游戏、玩法覆盖和接单服务场景的**产品推荐顺序**，不是玩家人数排行榜。管理员可以调整顺序。官方没有以同一日期、地域、终端和计算方式公布这 13 款游戏的完整日活表，因此不编造“当前第几名”或统一热度分数。

“首排”表达平台选择；“有日活证据”“有流水证据”“品类补充”表达证据强弱，三者不是人数高低等级。王者、和平等“长青”称谓来自腾讯定义，不能把该定义的门槛值写成某款游戏的实际日活。

## 运营时怎样调整

上线有真实数据后，按游戏观察近 30 天的访问用户、发布需求数、支付订单数、完成率、退款/争议率和复购率。优先提高有真实需求、履约稳定、退款率低的分类展示顺序。不要按“刷了多少浏览量”或累计注册量决定推荐。

服务应说明游戏端、区服、模式、数量/时长、交付条件和失败处理方式。交易闭环与证据规则共用，具体验收字段按游戏配置；推荐顺序变化不应改动历史订单快照。
