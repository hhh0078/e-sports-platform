## 用户检查清单与边界

1. 进入玩家页，依次切换各游戏并等待轮播，查看对应两段文字；滑动时图片先动，文字随后移动。
2. 管理后台进入游戏轮播设置，查看并编辑两段文字；保存后重新进入首页，确认使用新内容。
3. 个人手机重点看和平精英、金铲铲、三角洲、蛋仔的文字可读性，并检查胶囊下方与指示点附近。
