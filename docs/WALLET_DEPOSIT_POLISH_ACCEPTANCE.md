# 钱包弹层、押金补缴与上线验收

文件作用：记录2026-10-23本轮实际交付、验收证据、发布状态和运营者下一步测试；不把模拟资金、构建或上传当作实款及微信正式发布。

## 本轮行为

- 钱包充值、提现、缴退押金与提现规则共用官方 `UniPopup`。微信通过 `root-portal` 挂载，遮罩不推挤正文，忙碌时不能重复提交；手机号验证层高于资金表单，取消不创建资金单。
- 个人中心钱包改为紧凑标题金额行、三列在途分区和充值余额，保留可提现、进行中、结算中、提现中及不可提现的充值款。未知金额仍为占位，访客为零。
- 管理员分别设置个人、俱乐部平台最低押金。原押金继续托管，调高门槛后不足额只隐藏标识；页面显示还需补缴，输入默认差额，支持补至分。累计达到最低额恢复标识，个人押金仍自愿。
- 退款中的金额不参与资格。旧请求恢复、迟到付款与重复通知仍按原付款记账，不因新门槛丢账。成员给俱乐部的押金保持独立。
- 服务的黑金盾牌短角标缩至18px高度、8px文案，背景透明度0.76；金额版保留可读字号。列表、发布预览、个人及俱乐部公开资格统一由服务端决定。
- 开发读取本地地址；常规构建默认正式HTTPS域名并忽略私人本地配置，显式本地地址不能用于正式构建。本地微信测试使用独立模式和目录。
