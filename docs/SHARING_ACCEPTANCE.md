# 五类分享与公开需求交付说明

文件作用：记录首页、服务、公开需求、玩家和俱乐部的分享实现、验证证据、微信发布前提及用户测试清单。当前记录为2026-10-23本轮代码状态，真实发送/扫码能力不能用单元测试代替。

## 实现入口

| 内容 | 入口 | 好友/朋友圈目标 |
| --- | --- | --- |
| 首页 | 玩家页品牌“集结”右侧分享 | 首页玩家视图与当前游戏 |
| 服务 | 服务详情价格区域下方“分享服务” | 当前公开服务详情 |
| 公开需求 | 接单大厅点需求卡片 → 分享需求 | 脱敏公开需求详情 |
| 玩家 | 主页服务区标题右侧“分享主页” | 该玩家的公开资料和服务 |
| 俱乐部 | 主页原分享入口 | 该俱乐部的公开信息和成员 |

- 统一入口先显示官方弹层的“微信好友 / 生成分享海报”两种方式。访客可以直接分享好友；只有生成带个人资料海报时才登录并进入`pages/shares/create`。登录用户创建分享记录，服务端从真实会话取得分享人，不能用路由参数把被分享者冒充分享人。
- 海报每次由官方Canvas实时绘制750×1120图片。标题、简介、价格来自当前服务端元数据，底部左侧是分享人头像和昵称，右侧是官方真实小程序码，保留完整码图及白色净空（224px方形白底，内部码200px，不裁剪）。
- 好友封面独立绘制500×400；朋友圈封面独立绘制500×500。封面按中心裁剪，不把竖海报压成横图。长中英文、emoji按实测文本宽度换行/省略。
- “微信好友”使用官方`open-type=share`和`onShareAppMessage`；“朋友圈”使用`wx.showShareImageMenu`的图片分享入口；原页面三点菜单注册`onShareTimeline`，返回当前页面可识别的query和公开图片。
- `onShareTimeline`不能指定其他页面路径，所以分享生成页使用自己的`share_id`查询参数，朋友圈打开后匿名展示该记录，不能误用目标详情的query当成生成页参数。扫码统一进入`pages/shares/detail?scene=分享ID`，仅允许五个公共页面白名单。
- 二维码缺配置、目标不可见或微信返回JSON错误时不绘制海报，也不生成假码。已生成的好友封面可继续使用，错误可见并可重试。图片下载失败时使用打包的游戏封面兜底，真实码永不兜底。
- 朋友圈单页scene1154不调用`uni.login`，不读取本人资料，也不附带Bearer令牌读取公开内容。隐藏主底栏和交易动作；接单/下单/申请必须打开完整小程序。
- 公开需求详情只读`GET /jobs/:id`公开字段，不通过私有订单接口取得详情。接单经过登录、手机号、可用俱乐部选择和服务端资格校验；取消或切号不提交旧用户交易。

## 发布前必须配置

1. 后端使用对应小程序AppID/AppSecret，密钥仅服务端保存。管理员现有微信登录配置与该小程序一致，禁止在前端设置AppSecret。
2. 小程序后台把实际HTTPS后端域名同时加入`request`和`downloadFile`合法域名；托管封面、头像、码接口都应从同一已配置域名访问。当前项目域名为`game.ai.58it.cn`，生产构建API应为`https://game.ai.58it.cn/api`。
3. 发布的小程序包必须包含`pages/shares/detail`扫码落地页及`pages/requests/detail`公开需求页。后端生成正式码使用`env_version=release`、`check_path=true`。若尚未发布这些路由，微信会拒绝生成正式码，前端明确显示不能生成，不能关闭路径校验来伪造成功。
4. 具备新版微信基础库的手机才可直接使用`showShareImageMenu`；能力不足会提示保存海报后手动分享到朋友圈。相册权限只在用户主动点保存时申请。
5. 分享公开目标必须有效：服务已上架、需求待领取且已支付、玩家正常、俱乐部公开有效。内容暂停/被领取/被冻结后旧分享不应继续解析出私密或失效内容。

## 真机测试清单

1. 分别从首页、服务、公开需求、别人玩家主页、别人俱乐部主页打开分享选择弹层。访客选择微信好友不应要求登录；选择生成分享海报才登录并回跳。确认海报中的分享人是当前登录者，内容目标仍是所选页面。
2. 每类分别发送到一个测试聊天；检查聊天气泡有实际游戏封面、可读标题，打开后是对应目标。不要将“已打开系统菜单”当作发送成功。
3. 每类从三点菜单分享到朋友圈；检查1:1封面正常，点击后可匿名浏览，页面没有登录遮罩，不自动获取登录身份、不出现订单/手机号/私有成员审核数据。
4. 海报保存到相册，确认750×1120比例、底部左头像昵称、右真实码、长昵称省略、二维码四周留白，微信长按识别或另一台手机扫码能打开正确公开内容。
5. 从分享页点朋友圈，检查原生图片菜单展示并可以选择朋友圈；取消后保留海报，不提示“已发送”。旧版能力不支持时有恢复提示，可保存后自行分享。
6. 使用长标题、长简介、最大金额、中英文/emoji昵称及五个不同游戏验证。320/390设备上预览不得横向撑开、重叠或压扁。
7. 服务暂停、需求被他人领取、俱乐部停用后打开旧分享，确认显示失效或不可见，不进入订单聊天室。
8. 切换账号后返回分享页，旧账号头像和海报应清除，重新生成后显示新账号；快速连续点击不得混用两人的记录。
9. 断网、图片下载域名未配置、AppSecret缺失、正式落地页未发布、微信429/码接口JSON错误时，确认可读错误、重试和“不生成假码”；好友封面已准备好时仍可分享卡片。
10. 公开需求详情取消手机号授权或俱乐部选择后，确认仍保留需求显示，后台没有新增领取订单；另一个用户抢先领取时显示真实失败并刷新。
11. H5只用于公开浏览、海报Canvas预览和下载/复制链接，不把H5中按钮可见当作微信原生好友、朋友圈或相册权限已验收。
