7. **后台设置**：管理员编辑用户协议和隐私政策，确认版本变化；普通人访问配置接口应拒绝。支付私钥保存后不回显，留空保留原值。

仅本地体验：**登录页 → 勾选协议 → 开发体验**，或已登录后 **我的 → 个人资料 → 切换体验身份**。同一账号可同时买服务与接单。正式服务器不开放这些身份。

| 身份 | 名称 | 主要测试 |
| --- | --- | --- |
| 玩家 | 云间旅人 | 下单、付款、聊天、退款、验收、评价 |
| 打手 | 北辰 | 发布服务、接单、交付、处理退款 |
| 俱乐部管理员 | 山海主理人 | 审批挂靠、查看团队订单、参与聊天 |

## 1. 先看视觉与封面（约 5 分钟）

- [ ] 在“玩家”先看三角洲的黑绿主题，再切王者荣耀。王者封面应能认出李白、亚瑟、妲己、孙悟空，配色变为暖金色；不会混入其它游戏人物。
- [ ] 点击“全部 13 款”，可见三角洲、王者、和平、暗区、无畏契约、CF 手游、金铲铲、英雄联盟、源能行动、使命召唤手游、第五人格、永劫无间手游、蛋仔派对。搜索“蛋仔”后只显示蛋仔，点击可切换。
- [ ] 依次切换各游戏，背景、强调色、图标、主视觉、服务分类和服务卡片应跟随变化；默认三角洲选中时，王者、和平入口仍在首排。
- [ ] 搜索“路线”，三角洲应只显示匹配服务；输入不存在的词有空结果提示，清空能恢复。点击排序可直接选综合、价格、成交；价格从低到高，成交使用实际记录。
- [ ] 用“北辰”进入“打手 → 发布服务”，选择游戏时自动抽取对应底图。三角洲与王者各四张，其余各两张；点“换一张底图”应换成同一游戏的另一张。
- [ ] 添加最多 6 条文字，改文字颜色、背景颜色、字号与九宫格位置。默认从左下开始，依次向右排列，放不下换行；调整任一位置后其它文案自动避让。
- [ ] 改好文字后再换底图：文字内容、颜色、背景、字号和位置应全部保留。图片和文字是分开存储、分层显示的，文字没有烤进图片。
- [ ] 保存服务后切管理员审核，再回到大厅查看。列表、详情与编辑预览的封面配置应一致。
- [ ] 回到打手编辑已上架服务，保存后应重新进入审核；不能绕过平台直接上架。

## 2. 跑通一笔正常订单（约 8 分钟）

- [ ] 用“云间旅人”选择北辰的服务，填写区服、时间、服务目标与验收标准，选数量后下单。
- [ ] 金额应为单价乘数量；订单内展示下单时的服务说明、单价、单位，后续改商品不能改旧约定。
- [ ] 点击“支付订单”并确认测试付款，状态变为“等待接单”。
- [ ] 切“北辰”，在“订单 → 我接的单”进入，依次“接受订单 → 开始服务 → 提交交付”。每一步应留下系统记录。
- [ ] 双方在聊天室发送文字及一张截图；切换账号仍能看到，不能编辑或删除已发送证据。
- [ ] 切“云间旅人”，核对交付后“验收并完成”，再发布至少两个字的评价。
- [ ] 服务详情能看到真实评价；打手个人页完成数和收入统计更新。这里的收入为交易统计，不是真实钱包余额。

## 3. 测退款、拒绝与平台介入（约 8 分钟）

另建一单并支付、接单，避免影响上一笔正常交易。

- [ ] 买家点击“申请退款”，填写具体原因；申请期间暂停履约与结算。
- [ ] 打手可以“同意退款”，测试订单应全额退回并显示“已退款”。
- [ ] 再建一单，打手“拒绝退款”并说明依据；买家可补充申请、撤销或“申请平台介入”。
- [ ] 平台介入后，管理员从“我的 → 平台管理 → 订单与售后”进入，查看原始约定、交付、四方聊天和截图。
- [ ] 管理员填写理由后裁决“支持买方 · 原路退款”，或“驳回申请 · 继续履约”。已经交付的单还可裁决“支持卖方 · 确认完成”。
- [ ] 裁决和退款结果都有系统记录；退款单不能再次交付、完成或重复退款。
- [ ] 完成订单在 7 天内可申请售后；成功退款后从打手收入统计扣除。

## 4. 测俱乐部与四方聊天室（约 5 分钟）

- [ ] “自由玩家”可开启接单身份并独立发布，不加入俱乐部也能接单。
- [ ] 在“我的俱乐部”创建一个新俱乐部；管理员审核通过后可接收成员申请。
- [ ] 同一打手可以申请多个俱乐部。各俱乐部负责人只审批自己组织的申请。
- [ ] 挂靠审核通过后，发布服务时可以选择关联俱乐部；待审、拒绝或已退出的组织不能使用。
- [ ] 从挂靠服务下单后，“山海主理人”可在团队订单查看并聊天，不能代替打手交付或代替老板验收。
- [ ] 平台管理员也能进入同一订单。聊天中应明确标记老板、打手、俱乐部、平台身份。
- [ ] 打手退出俱乐部后新服务不再展示该认证，历史订单仍按下单时组织保留证据访问关系。

## 5. 测公开需求（约 4 分钟）

- [ ] 买家从首页“发布需求”填写标题、预算和验收要求，支付后进入接单大厅。
- [ ] 无关用户只能看到公开标题、预算、游戏等信息，不能读私密需求、老板信息或聊天室。
- [ ] 打手领取时可选“独立接单”或自己的有效挂靠俱乐部；选择组织后对应负责人能参与该单。
- [ ] 同一需求只能被一个人领走，不能领取自己的需求。
- [ ] 未被领取的已支付需求可由买家取消并测试退款。

## 6. 测平台后台与权限（约 5 分钟）

- [ ] 管理员审核服务、俱乐部认证，冻结/解冻“自由玩家”；冻结后该用户原登录会话也应立即被拒绝。
- [ ] 游戏配置可改强调色、背景色、卡片色、文字色、分类、封面顺序、游戏排序。上传“独立图标”只影响入口图标；上传封面加入该游戏图库。保存、返回首页和刷新后均应保留。
- [ ] 修改公告和平台名称；首页同步变化，后台操作记录有留痕。
- [ ] 管理列表可搜索完整历史数据并加载更多，不只搜索当前 100 条。
- [ ] 复制任意订单链接，切成“自由玩家”访问：应显示无权访问，不能看到参与者或聊天。
- [ ] 普通用户访问后台应被拒绝；一个俱乐部管理员不能查看另一俱乐部的私有订单。
- [ ] 刷新页面/重新启动服务后，订单、审核、主题、评价与聊天图片仍在。
