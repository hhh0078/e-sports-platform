# 页面修订与钱包开发计划

文件作用：记录2026-10-22已确认的修改范围、资金约束与逐项验收依据；本轮持续执行，不以构建通过代替真实资金验收。

## 修改范围

1. 先行设计：恢复登录官方游戏拼图，首页左文右操作，俱乐部文字全部叠于图上，个人资料固定接单身份；新增钱包和管理员钱包图，支付弹层补余额渠道。
2. 统一图标：手柄使用与官方图标匹配的线宽、画布与居中规则，选中继承游戏主题色。
3. 身份：全部账号默认具备接单能力且不可关闭，账号冻结、手机号和真实资料要求仍由服务端判断。
4. 钱包：充值、可提现服务收入、待结算、提现冻结、有效押金与退还中的押金隔离；页面只读取服务端金额。
5. 平台押金：自愿、不阻止发布；列表独立标识，详情实际金额，退还中的金额不参与标识。
6. 资金后台：提现审核执行与拒绝、配置商家转账场景，复用已有加密支付密钥配置。
7. 清理实际无用空目录，保留用户已有main.ts修改和登录页版式调整。
8. 后台控制台：把原七页签长页改为核心摘要、待办、交易曲线与十二个模块入口；先完成对应设计图再实施。
9. 管理页面拆分：用户、服务、俱乐部、订单售后、游戏、操作审计分别独立页面；平台名称与公告另设平台设置；钱包审核保持独立；协议/支付沿用同一配置页面的两个安全初始页签。
10. 经营统计：7天、30天及自定义上海自然日周期，最长366日；服务实付与成功退款按各自发生时间独立展示，充值、押金与提现不进入服务成交额。

## 后台控制台与拆分边界

- `pages/manage/index.vue` 只承载核心数据、待办、交易曲线与十二个入口，不再堆叠全部资源和编辑表单。
- 独立资源页为 `manage/users.vue`、`services.vue`、`clubs.vue`、`orders.vue`、`games.vue`、`audit.vue`；各页保留具体布局和业务操作，共享 `ManageList` 的权限/搜索/加载/空错态，以及 `manage-resource.ts` 的分页与会话保护，不以动态参数大全页替代拆分。
- 平台基础设置为 `manage/platform.vue`；提现审核与商家转账公开配置为 `manage/wallet.vue`；`manage/settings.vue?tab=payment|agreements` 分别进入支付或协议。
- 游戏完整编辑保留四主题色、分类、独立图标、多封面和顺序、启用与排序，使用官方底部弹层及裁剪压缩；选图隐藏保留同账号草稿，离开或账号变化作废旧操作。
- 待办深链分别为服务/俱乐部 `status=pending` 及订单 `refund=1`。状态筛选在服务端分页前执行；用户搜索词变化后不能追加旧查询的下一页。
- 列表、统计、写入和确认弹框均校验当前管理员及页面生命周期；冷启动失败提供重新初始化与重试，不让页面只剩顶栏。
- 平台管理仅限平台管理员，普通玩家和俱乐部管理员不可读写平台资源。个人资料不放商户配置，已有支付秘密不回显、不持久缓存在客户端。
- 注册用户/订单是平台总览计数，周期成交额使用真实资金来源与发生时间，不混用旧完成订单合计。演示记录排除，本地模拟明确标注；历史不完整记录显示全历史待核账提示，不编造时间或收入。
- 十二个入口实际路由、统计定义与人工逐项验收详见[平台管理控制台说明](ADMIN_CONSOLE.md)。

## 资金规则

- 金额整数分；充值款仅消费，服务收入才可提现。余额支付优先充值款，再服务收入；退款精确恢复原分账。
- 验收后保留7天售后期，期间仍为待结算；无退款争议才释放。平台最终裁决禁止重复售后。
- 历史订单没有托管账本时不凭订单状态虚增收入，需单独核账迁移。
- 押金独立、原路分笔退款；作为买家或供方有待付款、进行中、待验收、退款争议均阻塞退还。
- 新建/支付/接单与押金退还采用相同用户锁顺序；账本变更在数据库事务内完成。
- 同账号、相同请求号、同载荷幂等；变更载荷冲突。支付/退款/提现未知结果保持原单查询，不凭本地超时解冻。
- 提现先冻结，平台审核；未发起可拒绝，已出网未知结果不能直接解冻。原生微信操作成功不代表到账。
- 真实商家转账须商户申请合适服务收入场景；配置不足明确失败，生产不能由客户端强制模拟。

## 验收

- TypeScript严格检查、前端规范门禁、真实页面逻辑测试、H5/微信构建。
- 后端普通测试与独立PG/Redis并发资金测试，核对权限、余额守恒、重放和原路退款。
- 微信开发工具320/390实际视口：图标颜色与线宽、胶囊避让、卡片边界、钱包空态和交易闭环。
- 后台控制台十二入口、三待办深链、服务端状态筛选、分页搜索、只读审计与游戏全字段编辑；验证普通玩家/俱乐部管理员无后台权限。
- 交易统计核对上海自然日、7/30/自定义、闰日/366日上限、实付与成功退款分日、其他钱包资金排除、历史待核账及空错态；Canvas在微信包内单独验收。
- 测试证据保存在output本轮目录；真实微信手机号、商户资金与真机仍分别记录，不混同本地模拟。
- 提交并推送本轮分支；生产部署只经宝塔MCP，工具不可用不借浏览器绕过。
