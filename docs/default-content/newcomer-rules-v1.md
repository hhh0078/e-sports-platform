# 新用户必读：交易与接单规则

这份新手说明帮助买家和接单者在开始协作前确认约定、保留凭证，并正确使用退款和争议处理流程。具体交易以当前协议、订单记录与页面规则为准。

## 先沟通，再下单

确认游戏、区服、时间、服务内容、计价单位和验收标准。服务不包含什么、可能需要多久，也应提前说明。不要只依赖封面宣传或口头保证。

发布服务、发布需求和下单前需要完成手机号验证。请如实填写资料，遵守平台与游戏官方规则，不发布外挂、作弊、账号密码买卖或其他违法违规内容。

## 看清费用与资金状态

订单金额、平台抽成及俱乐部抽成以该订单显示的锁定记录为准；加入俱乐部后也应先了解本俱乐部的规则。

充值余额目前仅用于平台消费，不等同于可提现收入。服务收入需满足结算及售后条件后才能申请提现；提现申请或微信确认不代表已经到账，请查看最终状态。

平台押金、成员俱乐部托管押金与俱乐部平台押金分别管理，不混作服务佣金。请在相应押金页面查看缴纳、补缴及退还条件。

## 留在订单内沟通和交付

请使用订单聊天室确认重要约定，及时提交交付说明和凭证；聊天图片、交付与售后记录可能用于责任判断。平台管理员及有权限的俱乐部管理者可按订单权限核查相关记录。

不要在聊天中发送账号密码、支付密钥或与交易无关的敏感信息。下单、补款和退款都应通过平台订单处理，不以私下口头承诺替代平台状态。

## 加价、减价都要确认

履约中如需加价，由接单者提出，买家确认并完成补款后生效。减价需要双方同意，差额按原付款渠道退还；平台余额付款的差额恢复到原余额分区。

已结算、已退款或争议中的订单不自动调价。请以订单上可操作的状态为准，不重复付款。

## 有争议，先协商再申请平台介入

买家可在原订单发起退款，接单者可查看原因并同意或拒绝。协商不成时，按页面申请平台介入，补充清楚的约定、交付和沟通证据。

平台将依据实际记录处理，不保证某一方的诉求一定成立。退款申请、审核通过与资金实际退回是不同阶段，请关注最终结果；结果未知时优先查询原订单，不反复创建新申请或支付。

## 保护自己的资料与权益

公开资料、服务、需求、俱乐部和评价图文均可能进入AI或人工审核。内容不合规时，请根据消息修改；不要通过重复提交相同内容绕过审核。

需要业务协助，请进入个人中心“联系客服”；技术支持联系方式不作为业务客服。开始交易前，也请阅读小程序内当前《用户协议》和《隐私政策》。
