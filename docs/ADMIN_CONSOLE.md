# 平台管理控制台与验收清单

文件作用：说明本轮管理控制台的真实入口、经营统计口径、权限边界及用户验收步骤。本文不包含账号、密钥或商户秘密。

## 进入方式与交付范围

使用平台管理员身份登录后，进入“我的 → 平台管理中心”。控制台路由为 `/pages/manage/index`，只展示核心数据、待办、交易曲线和管理模块入口，原来的七页签长列表已经拆开。

本轮变更仍是本地开发交付，尚未部署生产，代码提交和验收结果以本轮交付报告为准。服务器以前部署的版本不能视为已经包含本轮控制台、钱包及页面调整。真实微信手机号、商户支付、退款、转账和真机验收另行记录，不能以本地模拟或构建成功代替。

## 经营数据与时间口径

注册用户和全部订单来自平台总览，是全量计数。顶部“周期成交额”及曲线来自周期统计接口，随7天、30天、自定义日期变化，不使用旧的完成订单金额代替实付统计。

- 时间统一为 `Asia/Shanghai` 上海自然日。7天包含今天及前6天，30天包含今天及前29天；设备或服务器的本地时区不改变统计日期。
- 自定义开始、结束日期均包含在范围内，最多366个自然日。起止颠倒、不存在的日期、缺少任一日期或超过上限均会被校验。
- 成交额（GMV）按首次核实的服务订单实付金额及付款时间统计。订单状态本身不是资金凭据，还必须有相符的托管记录和支付来源。
- 成功退款按退款成功时间另行统计。退款申请、卖方拒绝、平台处理中或退款通道处理中均不算已成功退款。
- 微信提供有效成功时间时采用官方时间，否则采用平台首次核验入账时间。不得用订单创建或更新时间猜测付款、退款时间。
- 退款不会改写原付款日的成交额。比如1日实付100元、3日成功退100元，则1日成交额100元、3日退款额100元；两项按各自发生日展示。
- 充值、平台押金、押金退还、提现不计服务成交额或服务退款。成交额也不等于平台收入、利润、钱包余额或可提现金额。
- 没有交易的自然日保留零值；没有数据时诚实显示零基线与空态，不生成随机曲线。

标为演示的数据不计入经营统计。本地 `dev_mode` 下，实际走过模拟付款及托管流程的记录可以参与本地统计，但界面会显示“本地模拟数据”，不代表真实资金。

### 历史待核账

缺少可靠付款/退款时间、托管凭据或相符资金来源的历史订单，不凭“已付款”“已完成”等状态补出曲线、收入或余额。仍有可靠凭据的事件按其自身发生时间统计，缺失的对应事件等待核账。

“历史待核账订单数”是在已付款/已退款候选订单中识别的全历史待核查数量，不是当前选定周期的订单数。应先核对商户流水、原支付和托管记录，再按受控迁移流程处理；不要为了让曲线好看而修改订单时间或人工补金额。钱包的历史资金处理参见[资金配置与测试说明](WALLET_SETUP_AND_TEST.md)。

## 权限与配置安全

只有平台管理员能够看到管理入口及经营数据。普通玩家、打手、俱乐部管理员即使直接打开管理路由，也不能读取或提交平台管理资源；服务端对每个接口再次验证权限。俱乐部管理员的成员、团队订单权限仍局限于获准管理的俱乐部。

个人资料页不放商户配置。用户自己的钱包与平台钱包审核是两个入口。支付配置只回显公开字段及“是否已配置”，已保存的秘密不会回显；本次填写的秘密不写入本地持久缓存，保存或离开后清空。微信登录 AppSecret 属于服务器配置，不放前端，也不写进本文。

## 用户逐项验收

以下是待人工逐项操作的清单，复选框不代表已经通过。建议先在本地模拟环境完成，再单独做真实微信与商户验收。

### 控制台与权限

- [ ] 用平台管理员进入“我的 → 平台管理中心”，能看到三个核心指标、三个待办、曲线和十二个模块；没有原七页签长列表。
- [ ] 逐一点开十二个卡片，页面职责正确，返回可用，二级页面没有主底栏。
- [ ] 普通玩家与俱乐部管理员的个人中心没有平台管理入口；直接打开管理路由时明确限制访问，不显示统计、商户或旧管理员数据。
- [ ] 切换账号、离开页面再返回，旧搜索、旧统计和旧保存响应不覆盖新身份。
- [ ] 冷启动直接进入管理子页，初始化网络失败时有错误和重新核验入口；恢复网络可重试，不停留在空白页面。

### 统计与待办

- [ ] 依次切换7天、30天、自定义，日期和“周期成交额”同步变化；无数据时显示零基线，不造金额。
- [ ] 自定义单日、包含闰日、366日均可用；非法日期、颠倒日期、367日应被拒绝。
- [ ] 查看“统计口径”和历史待核账提示，能区分服务实付、成功退款与其他钱包资金。
- [ ] 在测试环境进行一笔服务付款与成功退款，按各自发生日期核对曲线；仅申请或处理中的退款不能计入成功退款。
- [ ] 充值、缴纳/退还押金、申请提现后，服务成交额不因此增加。
- [ ] 三个待办进入正确的服务端筛选结果；服务、俱乐部待审核结果不夹入其他状态。

### 各管理模块

- [ ] 用户：搜索、取消冻结确认、确认冻结、解冻均可用；冻结自己没有可执行操作；离开后确认旧弹框不会执行冻结。
- [ ] 服务：在专用测试服务上验证通过、拒绝、暂停；处理后当前筛选立即刷新；详情仍使用已有服务详情页。
- [ ] 俱乐部：验证通过并认证、拒绝、授予/取消认证；主页、成员、订单三个入口分别可用，未授权身份不能查看团队管理数据。
- [ ] 订单：搜索订单号、标题或双方；切换全部与退款争议；进入订单详情仍能查看聊天室、证据和原售后流程。
- [ ] 订单售后：在本地测试订单验证申请退款、卖方拒绝、买方申请平台介入、平台裁定及通道处理中提示，成功状态与账本结果一致。
- [ ] 游戏：在专用测试配置验证四种颜色、分类、简称、标语、启用、排序；保存后公共主题与列表更新，取消不改变原配置。
- [ ] 游戏图片：分别上传1:1图标和16:9封面，选择多张并核对首张及顺序；取消选图不丢草稿，上传中切换身份不回填旧图片。
- [ ] 钱包：按[资金测试清单](WALLET_SETUP_AND_TEST.md)验证充值、消费、七天待结算、收入提现、押金退还、拒绝及未知结果原单同步，不把模拟成功视为真实到账。
- [ ] 微信支付：已保存秘密不回显；填入测试草稿后取消、保存或离开，秘密清空；真实商户能力另行验收。
- [ ] 协议：发布两份有效协议新版本，登录页能阅读并要求主动同意；修改正文但沿用旧版本号时被拒绝。
- [ ] 平台设置：修改名称与公告，保存后公共配置同步；取消可恢复已保存值；失败时有明确提示。
- [ ] 审计：刚进行的审核、冻结、游戏或配置操作可查，搜索和分页可用，没有编辑/删除入口。
- [ ] AI 审核与系统消息：按[审核及消息测试清单](AI_MODERATION_MESSAGES.md)验证真实模型、秘密不回显、失败保留草稿、通知读后服务器删除及本机保留；未读通知不能提前删除。

### 界面与真实微信

- [ ] 在320与390宽度检查长昵称、长标题、ID、分类、按钮和图标：可以换行或受控滚动，没有横向撑开、重叠或把金额挤窄。
- [ ] 搜索有多页数据时验证“加载更多”；改关键词后直接点更多，也从新查询第一页开始，不混入旧列表。
- [ ] 微信开发工具与实际微信设备分别验收状态栏/胶囊、返回、Canvas曲线、图片裁剪压缩和官方弹层。
- [ ] 真实手机号授权、真实微信付款、退款通知、商家转账及最终到账单独验收；本地身份/测试支付和自动化脚本不能代替这些步骤。
