# 集结 · 行业调研与交易设计

文件作用：记录游戏服务平台的公开来源、产品判断和本地版本的交易规则依据。调研日期：2026-10-18。以下区分来源事实与本项目设计，不把竞品宣传数据当独立市场统计，也不把本地开发通过等同于微信上线许可。

## 行业判断

这个市场的核心是降低“找到合适的人、约清交付、出事能处理”的成本。比心偏向陪练、语音组队、技能展示和考核；代练通偏向需求发布、接单、进度验收和撤单仲裁。已经存在成熟替代品，因此集结的差异应落在普通人可直接发布服务、买卖同一身份、俱乐部作为可选信用背书、每单四方留证，而不是“增加一个游戏商品列表”。

比心的开发者介绍列出技术实测、真人核验与复考，说明信用并不只靠俱乐部图标。集结的认证应明确“平台审核的俱乐部”，不能暗示官方战队、游戏厂商担保或必胜；服务成交数和评分应来自真实完成订单。来源：[比心 App Store 开发者介绍](https://apps.apple.com/cn/app/%E6%AF%94%E5%BF%83-%E6%89%BE%E6%B8%B8%E6%88%8F%E9%99%AA%E7%BB%83%E4%B8%8A%E6%AF%94%E5%BF%83app%E5%B0%B1%E5%A4%9F%E4%BA%86/id1286964732)。

代练通官网说明其连接游戏高玩与普通玩家，覆盖多款热门游戏。其帮助中心把验收、撤单协商、客服介入、留言与截图放进订单流程。集结沿用这种可验证的履约原则，但不照搬竞品的账户共用方式、金额门槛或自动结算期限。来源：[代练通官网](https://www.dailiantong.com/)、[官方发单问题](https://help.dailiantong.com/contents/55/2106.html)、[官方客服介入注意事项](https://help.dailiantong.com/contents/34/1981.html)。

## 首版交易闭环

1. 服务发布先填写游戏、类型、单价/单位、交付范围、封面与标签，由平台审核后展示。玩家也可发布定制需求。
2. 下单固化服务内容、单价、数量、买卖双方及俱乐部归属；金额由后端计算，客户端不能自报总价。
3. 支付成功后指定打手接单或进入公开需求大厅。接单、开始服务、提交交付、买方验收都是不同事件，不能由卖方自行确认完成。
4. 每单聊天室提供老板、打手、订单关联俱乐部负责人、平台管理员四种身份；历史订单沿用下单时的俱乐部归属。文字、图片和系统事件作为同一份证据链，用户不能编辑或删除历史记录。
5. 买方可申请退款，卖方可同意或填写理由拒绝，买方可撤销、补充证据再次申请或申请平台介入。退款申请与履约阶段分开保存，申请/介入期间暂停结算。
6. 平台根据下单约定、双方留言、带时间的进度截图和交付内容作出有理由的处理；裁决写入审计与系统消息。不能把俱乐部管理员视为独立裁判，它与卖方有关系，应提供协助与证据。
7. 首版本地规则为完成后 7 天可申请售后，这属于本项目约定，不代表服务交易普遍适用法定“七天无理由”。重复支付、重复退款、并发抢单和重复评价必须服务端幂等或明确拒绝。

## 微信接入与当前边界

微信支付官方文档要求验证回调签名、处理重复通知，并结合查单确认支付结果。客户端支付 API 的 success 不能独立证明钱已到账。本地测试支付必须显式标识，不产生真实扣费；真实支付和退款需要商户配置后对签名、金额、商户号、订单号及回调重放进行联调。来源：[微信支付回调通知](https://pay.wechatpay.cn/doc/v3/partner/4012886152)、[微信支付开发指引](https://pay.wechatpay.cn/doc/v3/partner/4012884395)。后一个来源的“小程序支付（新）”在本次读取时标注灰度开放，仅用于核对通用原则，正式产品应按商户实际开通的常规支付能力接入，不能直接假定灰度接口可用。

微信登录、交易管理与类目审核需要正式 AppID、主体和管理后台权限。本次抓取微信开发者站的交易管理与 code2Session 页面失败，所以不据此声称该游戏服务类目已获准上线。待正式账号具备后，应以后台最新类目、资质与交易保障要求核验。参考入口：[微信小程序交易管理](https://developers.weixin.qq.com/miniprogram/product/transaction.html)、[微信 code2Session](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html)。

## 运营验证建议

先用少量真实、经过审核的服务验证首批玩家能否找到人、多久接单、是否按约交付以及争议能否判清。首轮看首单转化、接单时长、完成率、退款率、复购率和争议处理时长；未做真实运营前不编造流量、收入、成交量和市场规模。俱乐部数量本身不是成功指标，能持续履约和留存才是。
