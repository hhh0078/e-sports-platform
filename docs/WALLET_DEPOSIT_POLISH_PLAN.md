# 钱包弹层与押金补缴实施计划

文件作用：记录本轮已确认的范围、实现顺序与验收边界。

1. 先更新钱包、个人中心、俱乐部资金、财务设置与角标设计图，再实现共享官方弹层和紧凑钱包布局。
2. 个人与俱乐部的平台押金最低额分别由平台管理员配置。个人押金仍自愿；有效押金达到最低额才展示标识。调整门槛后原资金保留，不自动退回余额，差额可补缴；缴纳输入默认差额。成员俱乐部托管押金保持独立。
3. 新缴纳意图校验累计有效金额；原请求恢复和支付成功记账不能被新门槛阻断。保留原退款条件、来源与幂等。
4. 开发默认本地 API；所有正式构建默认 https://game.ai.58it.cn/api，专用模拟器构建显式使用本地模式并输出隔离目录。
5. 执行前端类型、规范、测试、H5/微信构建、Go真实数据库测试；320/390核验弹层、差额、角标和权限，单独记录真实支付及真机边界。
6. 提交推送后，通过宝塔 MCP 核对生产、备份、构建、切换后端容器；核验健康、公开API及安全配置。保留配置和数据库卷，不带入本地模拟账本。
