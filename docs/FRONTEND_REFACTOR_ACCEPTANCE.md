# 前端规范与页面重构验收

文件作用：记录2026年10月22日本次前端整理的已证实结果、设计对应关系和手动测试清单；只按本轮真实报告记录通过项，真人与生产能力另列。

## 1. 本次改动与强制入口

- 根目录 `AGENTS.md` 强制每次开发前完整读取 `PROJECT_DEVELOPMENT.md`。规范明确先检查现有差异、先设计再实现、接口分层、类型检查、统一视觉与逐项验收。
- 原有未提交界面改动已保留并在 `.run/pre-standards-20261022.patch` 保存差异。本次在独立分支整理，没有将后端改写为TypeScript，也没有借本次重构更改生产数据库。
- 前端业务、工具、测试、入口和构建配置迁移TypeScript；Vue业务脚本声明 `lang="ts"`。`vue-tsc` 检查页面模板和源代码，独立 `tsc` 检查测试代码；没有通过忽略类型检查完成迁移。
- `src/api/client.ts` 是唯一请求与上传传输层；八个领域文件分别为 `auth.api.ts`、`games.api.ts`、`services.api.ts`、`orders.api.ts`、`clubs.api.ts`、`users.api.ts`、`admin.api.ts`、`media.api.ts`。页面调用具名业务方法，令牌和错误解析使用共享工具。
- 页面按main、services、requests、orders、account、community、manage业务目录整理。路由工具将已有内部入口归一到新路径，并保留查询参数；四个主视图的业务逻辑、会话保护和分页独立于视觉层。

## 2. 设计与共享组件

- `frontend/src/pages/` 当前18个页面/视图，在 `design/pages/` 都有同相对路径、同名前缀PNG与 `.design.md`。主页面、展示型详情与二级表单已按最新需求更新设计；打手和订单场景插画与实际PNG素材对应，个人中心改用当前游戏封面。图稿制作记录见 `design/README.md` 与 `design/prompts.json`，前两轮设计分别保存在 `design/history/20261022-before-immersive/pages/` 与 `design/history/20261022-before-secondary-unify/pages/`，实际验收截图独立保存于 `output/`。
- 玩家、打手、订单、我的四个主视图均无应用顶部导航、重复页面标题或返回按钮。唯一主页面 `pages/main/index.vue` 挂载一次底栏并保留四个内容视图；读取原生状态栏和胶囊尺寸，首行内容避让胶囊。普通标签切换保留筛选、已加载分页与各页滚动位置，返回后刷新原有已加载范围。
- 游戏入口统一为单行横向目录，右侧“全部”入口固定；展开官方弹层可搜索全部启用游戏。显式选择保存到本地 `jijie_game` 缓存，再次进入时恢复；只浏览另一游戏的详情不改写主游戏选择，卡片和详情按各自游戏显示局部主题。
- 打手工作台使用背景上的身份和统计、短标题、36px发布入口、文字订单入口及耳机/手柄场景插画；订单空态使用双手柄/地图插画与轻入口，不再套虚线框或巨型登录按钮；个人中心从顶部展示动态 `game.cover_url` 与中性灰黑蒙版，约240px的顶部区域包含原生安全区，身份行之后正常排列统计；昵称单行省略、简介最多两行，主题切换同步换图，不再使用通行证插画。下方保留居中快捷项和细分隔列表。插画源与历史素材用途见 `design/ILLUSTRATIONS.md`，所有身份、统计和操作均为独立UI元素。
- 全局样式集中维护主题、表面、文本、边框、间距、按钮与输入控件规格。默认水平边距16px，常用间距8/12/16/24px；主按钮44px、紧凑操作36px、轻入口至少28px，图标固定占位并居中。
- 本轮二级页面采用开放分节设计，复用 `.form-section`、`.subtle-note`、`.action-footer`，避免大卡片再套输入卡片。登录保留两行主标题、独立协议勾选和可跳过资料弹层；资料设置使用56px头像、开放输入与真实16:9封面，按内容自然滚动；需求发布按游戏、标题、验收标准和预算顺序排布。每个任务保留一个44px主提交，取消、查看和分享使用文字入口。先行图和约束均位于 `design/pages/` 对应页面路径。
- 二级页面没有主底栏。表单、登录、订单履约及管理页使用 `AppShell` 与官方 `uni-nav-bar` 包装的 `PageHeader`；服务详情、俱乐部主页及有封面的玩家主页采用沉浸展示和共享 `FloatingBack` 圆形返回，不再重复叠加应用顶栏。圆返回同样避让原生状态栏和胶囊，有历史时回上页、无历史时回主页面。
- 已设置个人封面时按 `community/players/detail-cover.png` 从页面顶部展示16:9封面，身份内容在图下正常排列；无封面时按 `detail.png` 显示统一功能顶栏，不保留空封面占位。两种状态均不使用负边距让头像或正文侵入封面。
- 官方 `uni-icons` 提供主要图标；官方库缺少的游戏手柄由统一 `Icon` 内的同粗细图形补足。开关包装器转发官方switch事件；`pages.json` 的easycom规则显式解析 `uni-*` 及其内部依赖。共享组件和常驻视图只使用类选择器，避免WXSS静默忽略标签、属性等选择器；最终结果仍以实际产物与运行日志为准。
- 服务列表、工作台、公开主页与发布预览统一使用 `ServiceCard`。游戏源封面通常为16:9，卡片按约4:3裁切；自定义文案、游戏/类别/认证标签和服务标题均为独立元素，标签在上、标题在下地悬浮于图内，底部渐变从透明过渡到完全不透明的对应游戏背景。封面布局为标签和标题预留实际像素区域，六条自定义文案不能侵入或互相重叠。价格、成交数及编辑/状态入口位于图片下方的正常文档流；换图不合成或丢失文字。服务详情沿用图内标签/标题与图下价格规则，并按详情尺寸另留安全空间。

## 5. 验收证据与运行方式

界面证据在 `output/frontend-standards/`，设计和实际并排图在 `design-comparison/`；根目录 `design-qa.md` 记录视觉修正循环。失败日志保留，不用后续成功覆盖失败历史。

本轮保存的独立验收后端与小程序编译地址均为 `http://127.0.0.1:18091/api`；常规 `./scripts/dev-start.sh` 固定启动8090。复测时客户端编译地址、`UI_TEST_API` 和 `TEST_API_BASE` 必须一致，且后端明确返回 `dev_mode=true`。新目录须先通过开发者工具主页正式导入登记再启用自动化；临时`cli open`只作人工预览。完整本地包编译及工具打开步骤见 [微信模拟器复测](WECHAT_SETUP.md#复现微信模拟器-ui-验收当前命令)。正式HTTPS包只用于正式能力验收，不用于本地模拟交易。

在项目根目录先按所用环境选择API；以下示例适用于常规8090开发后端：

```bash
JIJIE_TEST_API=http://127.0.0.1:8090/api
VITE_API_BASE="$JIJIE_TEST_API" UNI_OUTPUT_DIR="$PWD/frontend/dist/local/mp-weixin" npm --prefix frontend run build:mp-weixin
/Applications/wechatwebdevtools.app/Contents/MacOS/cli open --project "$PWD/frontend/dist/local/mp-weixin"
```

以上可打开人工预览。首次自动化先在开发者工具主页正式导入并登记此目录，确认AppID与本地数据正常，再启用：

```sh
/Applications/wechatwebdevtools.app/Contents/MacOS/cli auto --project "$PWD/frontend/dist/local/mp-weixin" --auto-port 9420 --trust-project
```

完成编译并选择390px机型后执行第一条；切到320px机型再执行第二条。输出使用独立 `recheck/` 目录，保留上文已记录的最终证据：

```bash
UI_TEST_PROJECT="$PWD/frontend/dist/local/mp-weixin" UI_TEST_API="$JIJIE_TEST_API" UI_EXPECT_WIDTH=390 UI_TEST_OUTPUT=output/frontend-standards/recheck/mini-ui-390 frontend/node_modules/.bin/tsx scripts/mini-ui-regression.ts
UI_TEST_PROJECT="$PWD/frontend/dist/local/mp-weixin" UI_TEST_API="$JIJIE_TEST_API" UI_EXPECT_WIDTH=320 UI_TEST_OUTPUT=output/frontend-standards/recheck/mini-ui-320 frontend/node_modules/.bin/tsx scripts/mini-ui-regression.ts
TEST_API_BASE="$JIJIE_TEST_API" TEST_EVIDENCE_DIR=output/frontend-standards/recheck/transaction frontend/node_modules/.bin/tsx scripts/mini-transaction.ts
```
