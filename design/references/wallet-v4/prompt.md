# 我的钱包设计提示词

文件作用：保存本轮内置ImageGen的视觉简报、输入角色和实现约束；原截图不作为产品图片使用。

输入：用户提供的旧钱包截图，角色为需要重新设计的界面参考；生成数量1。执行方式：内置image_gen编辑/重设计。生成原图为977×1610，开发基线390×844，微信原生状态栏独立适配。

提示词核心：重新设计中文“我的钱包”，深色游戏服务风格、温暖石墨底色、米白文字，参考色为香槟金，禁止蓝紫渐变。顶部返回、微信胶囊、钱包规则。第一区是金币余额0.00金币、购买金币及“仅用于小程序消费”，用低对比手柄标识营造游戏钱包特征；第二区账户余额¥2.00、可提现¥0.00、提现按钮及进行中/结算中/提现中三列；第三区自愿平台押金¥0.00、目标¥30.00及差额、补缴入口；底部资金明细四标签与真实空态。不要墙式说明、虚构收益或交易记录。长规则只放在点击后的独立说明。所有金额都是设计示例。

用户后续明确要求：卡片颜色跟随当前游戏颜色。实现使用当前游戏主色派生半透明底色与边框，按钮和选中态同步；字体、金额白色保持对比度。金色、橙色、绿色均验收。参考图中的图标采用现有Icon组件，不烘焙文字、不把整张设计图当页面。

视觉意图：玩家核对余额、购买金币或申请提现；金额是第一视觉，规则入口为次要层级。层级使用大额数字、16px分组标题、12至14px次要文字；8px基础节奏，主卡片20px内边距，16px页面边距，44px实际触控。深色基底、稍亮表面和低透明主题染色形成层级。金币、人民币、押金保持独立，是本产品的信息特征。避免等大卡片、长说明直接外露、无意义装饰和同权重文字。
