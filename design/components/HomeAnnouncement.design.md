# 首页公告浮层

文件作用：先行图`HomeAnnouncement.png`仅确认公告弹层，不采纳生成图背景中的其它首页设计。

- 官方UniPopup与微信根层，半透明遮罩；文字模式自然深绿底，清晰标题和多行正文，末尾可选详情入口。
- 图片模式不画卡片背景，使用上传图原比例widthFix；超高内容在有限视口内正常滚动，原图不裁剪。不因模式切换加入虚假图文。
- 独立清晰关闭图标及“关闭”文字，适配黑／白图片背景；实际关闭行为释放与版本更新共用的提示槽。
- 真正显示后才按公告版本记已读，账号与访客存储分离；关闭本次不立即再次打开。切号、隐藏和版本变化取消旧请求，登录跨设备已读以服务器为准。
- 内置ImageGen提示为“黑绿首页真实公告浮层、三段换行、下方明确关闭”；390×844。背景仅示意，不改变现有首页结构。
