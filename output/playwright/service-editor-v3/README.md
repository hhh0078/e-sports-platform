# 服务编辑分区与独立预览验收

文件作用：记录2026-11-17服务编辑页改造的实际界面证据及验证边界；截图为真实运行界面，不代替先行设计图。

## 已实现

封面底图、封面文字、服务信息独立分节；添加文字置于文字区右上角，最多六条，每条单独带边框与间距。颜色默认显示当前色，点开后选择常用色或输入自定义色值。字体选择用当前文案展示系统字和六款艺术字的实际效果。

编辑页使用“下一步预览”，校验后补存白名单草稿并打开独立预览页。预览复用完整ServiceCard，单独展示说明和须知，提供返回修改、确认发布/保存。账号、类型、编辑ID隔离缓存；原实例返回不重问，重进可恢复；成功精确清理，失败和晚到响应不能丢失新输入。
