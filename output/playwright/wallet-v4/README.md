文件作用：记录本轮布局、规则收纳和主题切换验收；所有金额、账号和接口均为合成夹具。

1. 我的钱包：金币/人民币/押金分别展示，钱包规则和提现规则保持可读；打开金币购买表单未提交。
2. 俱乐部资金：佣金主卡、三列状态、组织押金；规则收纳托管、门槛和退还条件。
3. 成员押金：托管主额、当前门槛、退还中、缴退操作，长托管规则收进弹层。
4. 交易规则：保留两费率和两最低押金字段，配置生效/历史订单说明收进弹层，保留主保存。
