## 本轮内容

1. 统一个人中心游戏背景与灰黑蒙版、首页左文右操作、玩家图标线宽/颜色、俱乐部图片叠字卡片与服务押金标识；接单身份默认开启且不可关闭。
2. 钱包区分充值、可提现收入、待结算、提现冻结和独立押金；保留微信充值/退款/商家转账配置入口及服务端校验。充值不能提现，验收7天且无售后才结算收入，有在途订单不能退押金。
3. 平台控制台使用十二个独立模块入口，交易/退款曲线按真实资金时间统计，支持7天、30天与最多366天自定义区间；修复旧Canvas八位透明颜色告警。
4. 管理员独立配置AI地址、模型、密钥与审查提示词；生产无配置、故障或非法响应暂停提交；密钥不回显，旧接口和图片引用也必须通过审核。
5. 消息列表只显示标题，新消息未读；打开详情先按账号保存本机全文/已读，再删服务器本人副本；存储失败不删、网络失败重试、切号隔离。
6. `GameSelector.vue` 复用首页搜索网格，覆盖玩家/打手、服务发布与编辑、需求发布、创建俱乐部和装修。表单不改首页游戏偏好，多选取消不回填；修复首次微信ref晚绑定、关闭动画与快速重开时序。

## 建议逐项手测

1. 六类游戏入口：搜索、单选、多选取消/确认；关闭后快速再开；创建俱乐部期间确认名称草稿仍在，返回首页游戏没有被表单改写。
2. 四个主导航与二级返回：游客空态、当前游戏个人中心背景、服务六条长文案、窄屏无溢出；服务文字是独立图层。
3. 我的 → 钱包：充值、押金缴纳/退还、收入结算和提现；有进行中订单拒绝退押金。商户配置只在平台管理。
4. 平台管理 → AI设置：填写真实密钥后测试正常/拒绝文字与图片，以及错误配置；生产审核服务故障必须拒绝该次提交并保留草稿。
5. 平台管理 → 系统消息：指定用户/广播；用户查看后重启仍有本地历史，切号无串号，服务器副本删除不影响订单聊天证据。
6. 按 [完整用户清单](../../docs/USER_TEST_CHECKLIST.md) 与 [部署流程](../../docs/DEPLOYMENT.md) 完成真实微信、手机号、商户资金及真机验收。
